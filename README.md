# Mock E-Com Cart — Vibe Commerce Screening

## Overview
A simple full-stack shopping cart app:
- Backend: Node/Express + SQLite
- Frontend: React (Vite)
- Features: Add/remove/update cart items, persistent DB, mock checkout (receipt), responsive UI.

## Structure
- `/backend` — Node server and SQLite DB
- `/frontend` — React app (Vite)

## Run locally

### Backend
```bash
cd backend
npm install
# start server
npm run dev   # or `npm start`
# server runs on http://localhost:4000
